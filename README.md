# Modern Maharani — Premium Digital Showroom

A luxury, contemporary digital showroom for **Modern Maharani**, a women's fashion boutique located in **KPHB Phase 1, Kukatpally, Hyderabad**.

## 🌟 Key Features

- **Luxury Editorial Design**: Tailored fashion color palette (Warm Ivory, Deep Charcoal, Deep Wine, Soft Champagne), custom serif typography, spacious layouts, and smooth animations.
- **Showroom Catalog (`/shop`)**: Browse Kurtis, Dresses, Occasion Wear, and New Arrivals with real-time category filters, size filters (S, M, L, XL, XXL), style tags (*Find Your Look*), price sorting, wishlist, and search.
- **Dedicated Product Detail Page (`/product/[slug]`)**: Image gallery, availability status (*Check Availability, In Store, Limited Stock, Out of Stock, Coming Soon*), price details, fabric specs, and direct conversion CTAs:
  - **Enquire on WhatsApp**: Generates pre-filled product enquiry messages.
  - **Check Availability**: Opens direct enquiry modal.
  - **Visit Store**: Direct link to showroom location guide.
- **Physical Store Guide (`/visit-us`)**: KPHB Phase 1 location details (*Flat-101, MIG-37, Road No. 1, opp. Global Eye Hospital, beside Swiss Castle Line, Kukatpally, Hyderabad*), operating hours, Google Maps directions, and live embedded map.
- **Full Admin CMS (`/admin`)**: Complete management dashboard for:
  - Products (Add/Edit/Delete/Duplicate, pricing, sizes, availability, badges)
  - Collections & Categories
  - Customer Enquiries & Status Tracking (*New, Contacted, Visit Planned, Purchased, etc.*)
  - WhatsApp Lead Analytics
  - Homepage Hero Banners & Copy Editor
  - Customer Reviews Approval

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the digital showroom.
Access [http://localhost:3000/admin](http://localhost:3000/admin) to manage content.
